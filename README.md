# Image Toolbox（图片信息查看与简单编辑工具）

> 项目骨架初始化中。完整的项目介绍、环境配置与运行示例将在功能开发完成后补齐。

## 项目介绍

用 Python + OpenCV 编写的命令行工具，用于读取图片基础信息并完成几种简单的图片编辑。

## 支持的功能

- 读取图片信息：文件名、格式、宽高、颜色模式、文件大小
- 简单编辑：缩放、裁剪、旋转、翻转、灰度化、格式转换

## 程序形式

命令行程序（CLI）。
